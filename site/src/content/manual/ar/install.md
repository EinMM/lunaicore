نزّل ملف التثبيت من [صفحة التحميل](/ar/downloads/). اسم الملف `{{installerName}}` وحجمه {{sizeMB}} ميجابايت.

<h2 id="verify">التحقق من ملف التثبيت</h2>

نفّذ هذا الأمر في PowerShell داخل مجلد الملف المنزَّل:

```text
Get-FileHash .\{{installerName}} -Algorithm SHA256
```

يجب أن تطابق النتيجة هذه البصمة (SHA-256) تمامًا:

```text
{{sha256}}
```

## تثبيت لونا

شغّل ملف التثبيت ووافق على صفحتي [شروط الاستخدام](/ar/legal/terms/) و[سياسة الخصوصية](/ar/legal/privacy/). تُثبَّت لونا لكل مستخدم، دون الحاجة إلى صلاحيات المسؤول، في:

```text
%LOCALAPPDATA%\Programs\Luna
```

## تحذير SmartScreen

ملف التثبيت التجريبي غير موقّع رقميًا بعد، لذلك قد تظهر رسالة «Windows protected your PC». اضغط More info ثم Run anyway، ولا تفعل ذلك إلا مع الملفات المنزّلة من [صفحة التحميل](/ar/downloads/) أو من [صفحة الإصدارات](https://github.com/EinMM/lunaicore/releases) الرسمية.

## التشغيل لأول مرة

شغّل لونا واتبع شاشة الترحيب والإعداد. تسألك عن اللغة، وطريقة تشغيل لونا (محلي، أو الذكاء السحابي، أو هجين، أو أقرّر لاحقًا)، ومجلد مساحة العمل. دع لونا تختار أو تنزّل نموذجًا محليًا مناسبًا لجهازك. وقبل أي تنزيل تعرض لونا الحجم والترخيص والمصدر. انظر [البدء](/ar/docs/desktop/getting-started/).

## محرّك NVIDIA

يأتي مع ملف التثبيت محرّكا المعالج وVulkan. وعلى جهاز فيه كرت NVIDIA تعرض لونا تنزيل محرّك NVIDIA ‏(CUDA 13.4، نحو 583 ميجابايت) في الترحيب وفي الإعدادات ← النموذج والمحرّك. ويحتاج تعريف NVIDIA بإصدار 580 أو أحدث. انظر [متطلبات التشغيل](/ar/docs/desktop/requirements/).

## مكان بياناتك

تحفظ لونا بياناتك على جهازك، في `%LOCALAPPDATA%\EinMM\LunaAI\data\`. يمكنك فتحه من الإعدادات ← البيانات والخصوصية ← فتح مجلد البيانات.

## إلغاء التثبيت

لإلغاء تثبيت لونا، استخدم إعدادات Windows ← التطبيقات ← لونا ← إلغاء التثبيت. يسألك برنامج إلغاء التثبيت عن حذف بياناتك أيضًا، وعن حذف النماذج والمحرّك اللذين نزّلتهما، وعن حذف مفاتيح API المحفوظة. ولا يُحذف مجلد العمل أبدًا. وتوضّح [سياسة الخصوصية](/ar/legal/privacy/) كل حالة.
