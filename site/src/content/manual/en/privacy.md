## Where is my data?

On this computer, in `%LOCALAPPDATA%\EinMM\LunaAI\data`: conversations, memories, "About you", settings and logs. Settings → Data & privacy → Open data folder opens it.

## What leaves my computer?

The [Privacy Policy](/legal/privacy/) lists every case. With Luna Engine, nothing is sent to answer you. Private conversations 🔒 never go to the cloud. For web search and reading web pages, see [Web search](/docs/desktop/web-search/). The page [Privacy & Security](/privacy-security/) gives an overview.

💡 Tip: for health, money or family matters, make the conversation private 🔒 before you start.

## Secrets

Before a cloud send, Luna checks your message for things like passwords, PINs, verification codes, API keys and card or ID numbers, and asks you what to do. In other content (memories, documents, tool results) such items are hidden before sending.

## Logs

The activity log records which tools ran. The model error log keeps replies Luna could not understand, to help solve problems. Both stay on your computer and are not sent anywhere automatically.

## Your API key

Kept only in Windows Credential Manager, never in a file. Web search keys are kept the same way.
