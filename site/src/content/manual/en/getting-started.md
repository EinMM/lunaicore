## What is Luna?

Luna is a desktop assistant. She chats with you and, when you ask, works with files in her workspace and in folders you allow. She can run on your computer with Luna Engine, or use a cloud AI (Gemini or OpenAI) with your own key.

## How do I start?

1. The first time, the first-run setup asks for the language, how Luna should run (Local, Cloud AI, Hybrid or Decide later) and the workspace folder. You can also tick the option to add a shortcut to this folder on your Desktop.
2. Type a message in the box at the bottom and press Enter.
3. The first message can take up to about 40 seconds while Luna Engine loads the model.

## What can I ask?

- Questions and writing help.
- File tasks: "List the files in my workspace", "Find a file named report", "Create a file named notes.txt containing: …".
- Reading Word, Excel and PDF files (text only, no images).
- "Remember that …" to save a short memory.
- Questions about Luna herself: Luna answers from the user guide. To be sure the answer comes from the guide only, start your message with /help, for example: /help What is speed mode?

## The navigation rail

On the side: Conversation, Chat History, Send feedback, User guide and Settings. The switch at the bottom changes the theme (dark, light or Follow Windows).

## Can I run the setup again?

Yes: Settings → General → Run first-run setup again. Your settings stay until you confirm each step.
