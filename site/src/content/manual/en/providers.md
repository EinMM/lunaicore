Luna works with the engines and services below.

## Local models

Models run on Luna Engine, built on llama.cpp. For the models that fit your graphics card, see [System requirements](/docs/desktop/requirements/).

- **Gemma**: Google’s open model family, run locally on your PC.
- **Qwen**: Alibaba’s open model family, run locally on your PC.

## Cloud AI

Optional. Use your own API key, stored in Windows Credential Manager.

- **Google Gemini**: connect with your own Google AI API key.
- **OpenAI**: connect with your own OpenAI API key.

## Web search

Optional. Luna supports Brave Search, Tavily and Mojeek, each with its own key from the service. See [Web search](/docs/desktop/web-search/).

Provider names and trademarks belong to their owners; Luna is an independent project and is not affiliated with or endorsed by them. The [Privacy Policy](/legal/privacy/) lists what is sent to each service.
