## Does Luna need internet?

Local model conversations can work without internet after the model is installed. You need the internet to download models and updates. See [System requirements](/docs/desktop/requirements/).

## Is cloud use required?

No. Cloud processing is optional and under your control. See [Cloud AI](/docs/desktop/cloud-ai/).

## Does Luna work on Windows 10?

Windows 11 is recommended. The installer allows Windows 10, but it is not officially supported.

## Why does Windows show a SmartScreen warning?

The Beta installer is not code-signed yet, so Windows may show “Windows protected your PC”. See [Installing Luna](/docs/desktop/install/) before you click Run anyway.

## How can I verify the installer?

Compare the SHA-256 of the downloaded file with the one on [Installing Luna](/docs/desktop/install/#verify).

## Does Luna change my files without asking?

No. Luna reads or changes files only in the folders you allow, and asks you to confirm every file operation. See [Files and permissions](/docs/desktop/files-and-permissions/).

## Where is my data?

On your PC, in `%LOCALAPPDATA%\EinMM\LunaAI\data`. See [Privacy](/docs/desktop/privacy/).

## Can Luna use the web?

Only when you allow it. Luna can read a web page from a link you write, and search the web with your own key. A private conversation never uses the web. See [Web search](/docs/desktop/web-search/).

## Which models and providers does Luna support?

See [Supported providers](/docs/desktop/providers/).

## How do I report a problem?

Use Send feedback in Luna (the side bar, or Settings → About Luna), or “Report a problem” at the bottom of this page, and read the tester guide first. Security issues must be reported privately, never in a public report: see the [Security Policy](/legal/security/).
