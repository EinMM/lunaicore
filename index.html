LOCAL & HYBRID INTELLIGENCE

Choose how Luna thinks.

Start locally and choose cloud processing when you need it.

Local

Everything runs on your computer with Luna Engine, and works offline once a model is installed.

Cloud

Use Google Gemini or OpenAI with your own API key, stored securely on your PC.

Hybrid

Local and cloud together, in one of two styles:

  • Balanced Local first. The cloud steps in only when the local engine is unavailable.
  • Lighten the PC The cloud handles everyday requests, while sensitive messages stay on your PC.

FAQ

Frequently asked questions

Does Luna need internet?

Local model conversations can work without internet after the model is installed.

Is cloud use required?

No. Cloud processing is optional and under your control.

Does Luna work on Windows 10?

Windows 11 (64-bit) is recommended. Windows 10 is not officially supported in this Beta: cloud AI works on it in our testing, but some features may not work as expected.

Why does Windows show a SmartScreen warning?

The Beta installer is not code-signed yet, so Windows may show “Windows protected your PC”. Click More info, then Run anyway — only for installers downloaded from this page or the official Releases page.

How can I verify the installer?

Run this command in PowerShell, in the folder of the downloaded file:

Get-FileHash .\LunaSetup-0.1.0.exe -Algorithm SHA256

The result must match this SHA-256 exactly:

2ed24c91382b8f8c5a6ded6797d0bfa05931c7fb508bb9096a386f6c7d30a1cc

How do I report a problem?

Use “Report a problem” at the bottom of this page, and read the tester guide first. Security issues must be reported privately, never in a public report.
